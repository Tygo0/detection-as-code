# ADS: Registry Run Key Persistence (T1547.001)

## Goal
Detect an adversary establishing persistence via a Registry Run key.

## Categorization
- ATT&CK: T1547.001 - Boot or Logon Autostart Execution: Registry Run Keys
- Tactic: Persistence

## Strategy abstract
Watch process-creation telemetry (Sysmon EID 1) for `reg.exe` adding a value under a
`...\CurrentVersion\Run` key. Run-key writes also appear as Sysmon EID 13 (registry).

## Technical context
Values under `HKCU`/`HKLM ...\CurrentVersion\Run` execute at logon. `reg.exe ADD` with a
Run-key path is a direct way to plant one. Verified with Atomic Red Team "Reg Key Run"
(`e55be3fd-3521-4610-9d1a-e210e42dcf05`).

## Blind spots and assumptions
- Run keys written via the Win32 registry API (not reg.exe) won't match this process rule;
  a companion EID 13 rule would cover that path.
- Does not evaluate whether the referenced binary is malicious.

## False positives
- Software installers that register autostart entries. Measured against the benign
  baseline (0 hits); narrow by value/target if that changes.

## Validation
- Fires on: `recordings/attack/T1547.001/e55be3fd-...evtx`
- Silent on: benign baseline. Enforced by `tests/test_detections.py`.

## Response
Inspect the Run value's data (the command it runs) and its origin; remove if unexpected.
