# ADS: Clear Windows Event Logs (T1685.005)

## Goal
Detect an adversary clearing a Windows event log to destroy evidence.

## Categorization
- ATT&CK: T1685.005 - Disable or Modify Tools: Clear Windows Event Logs (was T1070.001 pre-v19)
- Tactic: Defense Impairment

## Strategy abstract
Watch process-creation telemetry (Sysmon EID 1) for `wevtutil.exe` with a clear-log
argument (`cl` / `clear-log`). Log clearing also raises Security 1102.

## Technical context
`wevtutil cl <log>` wipes a log. Verified with Atomic Red Team "Clear Logs"
(`e6abb60e-26b8-41da-8aae-0c35174b0967`).

## Blind spots and assumptions
- Clearing via PowerShell `Clear-EventLog`/`wevtutil` wrappers or the API won't match the
  wevtutil process rule; a companion rule or Security 1102 would cover those.

## False positives
- Rare on endpoints; admins seldom clear logs this way. Benign baseline: 0 hits.

## Validation
- Fires on: `recordings/attack/T1685.005/e6abb60e-...evtx`
- Silent on: benign baseline. Enforced by `tests/test_detections.py`.

## Response
Treat as anti-forensics. Identify which log was cleared and correlate with surrounding
activity from forwarded logs (if any).
