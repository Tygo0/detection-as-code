# ADS: Rundll32 Proxy Execution of Script (T1218.011)

## Goal
Detect rundll32.exe being abused to proxy-execute inline script.

## Categorization
- ATT&CK: T1218.011 - System Binary Proxy Execution: Rundll32
- Tactic: Defense Evasion / Stealth

## Strategy abstract
Watch process-creation telemetry (Sysmon EID 1) for `rundll32.exe` whose command line
contains an inline `javascript:` or `vbscript:` scriptlet.

## Technical context
rundll32 can run inline script via the `mshtml,RunHTMLApplication` trick, letting
attackers execute code under a signed binary. Verified with Atomic Red Team "Rundll32
execute JavaScript Remote Payload With GetObject"
(`57ba4ce9-ee7a-4f27-9928-3c70c489b59d`).

## Blind spots and assumptions
- rundll32 loading a malicious DLL (no inline script) won't match this rule.
- Obfuscation that avoids the literal `javascript`/`vbscript` tokens would evade it
  (a candidate for the v1.1 evasion tests).

## False positives
- Rare; inline script via rundll32 is almost always malicious. Benign baseline: 0 hits.

## Validation
- Fires on: `recordings/attack/T1218.011/57ba4ce9-...evtx`
- Silent on: benign baseline. Enforced by `tests/test_detections.py`.

## Response
Capture the full command line and the remote URL it references; treat as code execution.
