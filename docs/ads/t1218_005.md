# ADS: Mshta Proxy Execution (T1218.005)

## Goal
Detect mshta.exe being abused to proxy-execute script or launch another interpreter.

## Categorization
- ATT&CK: T1218.005 - System Binary Proxy Execution: Mshta
- Tactic: Defense Evasion / Stealth

## Strategy abstract
Watch process-creation telemetry (Sysmon EID 1) for `mshta.exe` with an inline `about:`
HTA or an embedded `javascript`/`vbscript` scriptlet in its command line.

## Technical context
mshta executes HTML Applications and can run inline script, often chaining to PowerShell.
Verified with Atomic Red Team "Mshta used to Execute PowerShell"
(`8707a805-2b76-4f32-b1c0-14e558205772`).

## Blind spots and assumptions
- mshta executing a remote `.hta` by URL (no inline `about:`) may not match; extend the
  rule with a URL condition if needed.

## False positives
- Legacy line-of-business apps that still use HTA files. Benign baseline: 0 hits.

## Validation
- Fires on: `recordings/attack/T1218.005/8707a805-...evtx`
- Silent on: benign baseline. Enforced by `tests/test_detections.py`.

## Response
Decode the inline script / HTA and identify any spawned interpreter (e.g. powershell).
