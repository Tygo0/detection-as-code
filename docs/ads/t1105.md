# ADS: Ingress Tool Transfer via certutil (T1105)

## Goal
Detect downloading of a remote file using the living-off-the-land binary certutil.exe.

## Categorization
- ATT&CK: T1105 - Ingress Tool Transfer
- Tactic: Command and Control

## Strategy abstract
Watch process-creation telemetry (Sysmon EID 1) for `certutil.exe` with the `urlcache`
option, which fetches a URL to disk.

## Technical context
`certutil -urlcache -split -f <url> <file>` downloads a file - a common LOLBin transfer.
Verified with Atomic Red Team "certutil download (urlcache)"
(`dd3b61dd-7bbc-48cd-ab51-49ad1a776df0`). The command line is logged even when the
download fails (e.g. with networking disabled during recording), which is what we detect.

## Blind spots and assumptions
- Other download LOLBins (bitsadmin, curl, PowerShell) are separate detections.
- certutil's legitimate certificate functions do not use `urlcache`.

## False positives
- certutil has valid certificate uses, but `-urlcache` downloads are rarely benign.
  Benign baseline: 0 hits.

## Validation
- Fires on: `recordings/attack/T1105/dd3b61dd-...evtx`
- Silent on: benign baseline. Enforced by `tests/test_detections.py`.

## Response
Identify the URL and downloaded file; retrieve and analyze the artifact.
