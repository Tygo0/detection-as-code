# ADS: Encoded PowerShell Command (T1059.001)

## Goal
Detect PowerShell launched with an encoded command, a common obfuscation technique.

## Categorization
- ATT&CK: T1059.001 - Command and Scripting Interpreter: PowerShell
- Tactic: Execution

## Strategy abstract
Watch process-creation telemetry (Sysmon EID 1) for `powershell.exe` with an encoded
command switch (`-EncodedCommand`, `-enc`, `-ec`, `-e`) followed by a base64 blob. The
decoded content is also available in PowerShell 4104 script-block logs.

## Technical context
`-EncodedCommand` accepts base64-encoded UTF-16LE script, letting attackers hide intent on
the command line. Verified with Atomic Red Team "PowerShell Command Execution"
(`a538de64-1c74-46ed-aa60-b995ed302598`), which runs `powershell.exe -e <base64>`.

## Blind spots and assumptions
- Matches the encoded *switch*, not the payload; pairing with 4104 decode is recommended.
- Abbreviations beyond those listed, or encoding via stdin, could evade (v1.1 evasion tests).

## False positives
- Some legitimate tooling uses `-EncodedCommand`. Review the decoded payload. Benign
  baseline: 0 hits.

## Validation
- Fires on: `recordings/attack/T1059.001/a538de64-...evtx` (pending re-record with this GUID)
- Silent on: benign baseline. Enforced by `tests/test_detections.py`.

## Response
Decode the base64 argument (UTF-16LE) and assess the script; treat as code execution.
